# AI Price Poster Maker

AI-assisted price comparison and sale poster generator for local shops and small businesses.

## V1
- Upload a product photo
- Enter product name, MRP, and sale price
- Automatically calculate discount
- Choose from poster templates
- Preview the poster
- Download a PNG

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Roadmap
- V1: Core poster maker
- V2: AI copy, smart positioning, background removal, and multiple formats
- V3: Product comparison / price intelligence
- V4: Batch generation and brand kits
